# Plan: Análisis del Proyecto SQLtoUML - Problemas Identificados

## Resumen del Proyecto
- **Tipo**: Frontend SPA (Single Page Application)
- **Tecnologías**: React 18, TypeScript, Vite, Tailwind CSS, React Flow
- **Función**: Convertir SQL a diagramas UML/ER interactivos
- **Despliegue**: GitHub Pages

## Problemas Críticos (Urgentes)

### 1. **Bug Crítico en Eliminación de FK**
- **Archivo**: `src/parsers/sqlParser.ts`
- **Problema**: `parseDropTable` elimina FKs usando índice numérico en lugar del nombre del constraint
- **Riesgo**: Puede eliminar la FK incorrecta si hay múltiples foreign keys
- **Solución**: Usar el nombre del constraint para identificar la FK a eliminar

### 2. **Funciones Stub sin Implementar**
- **Archivo**: `src/converters/sqlToUml.ts`
- **Problema**: `getReferencedMultiplicity` y `determineRelationshipType` están vacías (solo retornan valores por defecto)
- **Riesgo**: Todas las relaciones se muestran como association sin multiplicidades reales
- **Solución**: Implementar lógica real basada en las constraint definitions

## Problemas Altos (Importantes)

### 3. **Código Duplicado Masivo**
- **Archivos**: `UmlRelationshipEdge.tsx` y `UmlStraightRelationshipEdge.tsx`
- **Problema**: ~200 líneas duplicadas (funciones geométricas, renderizado)
- **Solución**: Extraer funciones comunes a `src/utils/edgeGeometry.ts`

### 4. **Referencia a Dependencia Inexistente**
- **Archivo**: `vite.config.ts`
- **Problema**: `elkjs` en `optimizeDeps.include` pero no está en `package.json`
- **Solución**: Eliminar de la configuración o instalar si se necesita

### 5. **`console.log` en Producción**
- **Archivos**: Múltiples componentes
- **Problema**: Logs de debug visibles en consola del navegador
- **Solución**: Eliminar o reemplazar con sistema de logging configurable

### 6. **Falta de Validación SQL**
- **Archivo**: `src/parsers/sqlParser.ts`
- **Problema**: No valida SQL vacío, sintaxis incorrecta, o strings con `;` dentro
- **Solución**: Agregar validación básica y mensajes de error específicos

## Problemas Moderados

### 7. **`window.prompt()` sin Sanitización**
- **Archivos**: Todos los edges
- **Problema**: Input del usuario pasado directamente a `updateLabel()`
- **Solución**: Sanitizar input o usar componente de edición personalizado

### 8. **Múltiples Suscripciones al Store**
- **Archivos**: Todos los edges
- **Problema**: `useStore` con selectores separados crea suscripciones innecesarias
- **Solución**: Combinar en una sola llamada o usar `useReactFlow()`

### 9. **`useEffect` sin Guardia**
- **Archivo**: `App.tsx`
- **Problema**: `fontScale` actualiza todos los nodos incluso si no cambió
- **Solución**: Agregar condición de verificación antes de actualizar

### 10. **SQL de Ejemplo Duplicado**
- **Archivos**: `App.tsx` y `SqlEditor.tsx`
- **Problema**: Dos SQL de ejemplo diferentes causan confusión
- **Solución**: Unificar en una sola fuente

### 11. **Validación FK Referenciadas**
- **Archivo**: `src/converters/sqlToUml.ts`
- **Problema**: No verifica que tablas referenciadas existan
- **Solución**: Filtrar edges hacia tablas inexistentes

## Problemas Bajos

### 12. **Edge Context Innecesario**
- **Archivo**: `src/contexts/EdgeLabelContext.tsx`
- **Problema**: Context no necesario, funciones ya se pasan como props
- **Solución**: Eliminar Context, pasar funciones directamente

### 13. **Import Dinámico sin Error Handling**
- **Archivo**: `DiagramCanvas.tsx`
- **Problema**: `import('html-to-image')` sin catch para errores de carga
- **Solución**: Agregar try/catch para errores de importación

### 14. **Conflicto de Merge en LICENSE**
- **Archivo**: `LICENSE`
- **Problema**: Conflicto sin resolver (líneas 3-6)
- **Solución**: Resolver conflicto manteniendo licencia MIT

### 15. **Archivos de Verificación Duplicados**
- **Archivos**: `googlecd3f802072c499bd.html` (raíz y public/)
- **Problema**: Dos copias del mismo archivo
- **Solución**: Mantener solo en `public/`

## Infraestructura Faltante

### 16. **Sin Tests**
- No hay archivos de test ni configuración de testing
- **Solución**: Agregar Vitest + tests unitarios para parser y converters

### 17. **Sin Linting**
- No hay ESLint, Prettier ni herramientas de código
- **Solución**: Configurar ESLint + Prettier
